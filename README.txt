IRISH MYTHOLOGY: THE HERO'S JOURNEY
Canon Sheehan Primary School edition

LATEST CLASSROOM EDITION

This edition includes the original 43 trading-card images embedded in index.html, the expanded multi-level games and all 36 stories. The original trading-card artwork is retained unchanged.

NEW READING SUPPORTS
- Read Aloud controls on every story, using the device/browser speech voice.
- Clickable vocabulary helper for selected words in the stories.
- Three comprehension activities per story: the existing multiple-choice question plus two open-ended prompts.
- Reading settings for text size, line spacing and a clear sans-serif font. Settings are saved locally on the Chromebook.
- Character profile pronunciation buttons, using available device speech voices.
- Story search and random story selection are available in the Myth Library.

EXISTING FEATURES
- 43 original character trading cards and character profiles with links to related stories.
- Mythology Quiz, Who Am I?, Hero's Choice and Match the Treasures & Wonders with Apprentice, Hero and Legend levels.
- Put the Story in Order with increasing difficulty.
- Shorter and fuller reading versions for the stories.
- Local progress tracking without pupil accounts.

OPENING LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.

PUBLISHING
Upload index.html, manifest.webmanifest, service-worker.js and the assets folder together to the same website directory. The original card images are embedded in index.html. Keep assets/app-icon.svg for the site icon. Offline installation/service-worker features require the site to be hosted over HTTPS (or tested on localhost).

TECHNOLOGY NOTES
Read Aloud and name pronunciation use browser speech synthesis. Voice availability, accent and pronunciation vary by Chromebook and browser. The site prefers an Irish English voice where available, then British English, then another English voice. No separate audio recordings or audio subscription are required.

The website has not been published to the public internet.
